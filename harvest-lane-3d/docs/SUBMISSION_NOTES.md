# If the 3D edition is ever submitted to YouTube Playables

The live Playables submission draft (~/workspace/youtube-playables/
submission-draft.md) describes the 2D edition, which contains no
ads. The 3D edition differs in ways a submission must state:

- It contains optional rewarded ads: tapping the coin or gem pill
  offers +50 coins or +3 gems for watching an ad, paid only when
  the platform confirms completion. Any store description for the
  3D edition must declare rewarded advertising.
- Harvesting is walk-over (stepping on a ready crop collects it);
  the 2D edition uses a harvest action near a highlighted crop.
- Everything else (economy, missions, upgrades, South Field,
  animals, saves) matches the 2D edition's description.

Do not submit the 3D edition using the 2D description text.
